# Radares

Rotinas automáticas públicas da Arizona Marcas e Patentes Ltda (CNPJ 23.644.667/0001-22).

- **Radar de empresas novas de SP:** lê a base aberta do CNPJ da Receita Federal toda segunda e manda à Arizona, por token do próprio GitHub (sem senha guardada), as empresas abertas no mês anterior.

Este repositório guarda só código. Nenhum dado de empresa, cliente ou contato fica aqui: os registros das execuções mostram apenas contagens. Quem recebe e-mail pode sair da lista em um clique.
